# 🚀 Cybersecurity & Penetration Testing Lab Setup

**Networkwalks Cybersecurity Program | Batch B084 | Week 1 Project**

## 📌 Project Overview

This project focuses on building and configuring a virtual cybersecurity testing lab using **Oracle VirtualBox** and **Kali Linux**.

The goal was to create an isolated virtual environment for learning cybersecurity fundamentals, understanding virtual networking, and preparing for future hands-on penetration testing exercises.

## 🎯 Tasks Completed

- [x] Installed and configured Oracle VirtualBox.
- [x] Imported and configured Kali Linux.
- [x] Created and configured a private NAT Network.
- [x] Configured and verified Kali Linux network settings.
- [x] Tested network connectivity.
- [x] Verified DNS resolution.
- [x] Created a clean VM snapshot for recovery.
- [x] Documented the setup process with screenshots.

## 🧠 Key Learnings

Throughout this project, I gained practical experience with:

- Virtual machine installation and configuration.
- Understanding NAT vs. NAT Network.
- IP address configuration and network verification.
- Testing internet connectivity and DNS resolution.
- Virtual machine snapshots and recovery.
- Technical documentation and project organization.
